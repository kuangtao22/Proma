# 默认画布与修改定位：实施方案

状态：用户已确认，2026-09-16 已实施并验证；“默认”指画布列表的默认画布设置，不涉及素材采用。

## 目标

用户无需维护默认画布；普通聊天 Agent 修改画布时，应看见实际操作的画布及节点，且多任务更新不持续抢焦点。

## 实施前证据

- canvas-workspace-actions.ts 的 selectInitialCanvasWorkspaceSession 和 selectCanvasAfterArchive 仍优先 defaultCanvasId。binding 同时维护 defaultCanvasId 与 lastActiveCanvasId。
- canvas-tool-provider.ts 的 canvas_task status 和 canvas_context 部分状态查询使用 active/default 回退；核心写工具具有显式目标与权限合同，不能把去掉星标当成路由已经迁移。
- useGlobalAgentListeners.ts 的 startGlobalAgentCanvasArtifactConsumer 仅监听 canvas_create_artifact / canvas_import_image。agent-canvas-artifact-result.ts 又限定 webview / image 成功结果，文档、音视频和多种更新未统一覆盖。
- navigateAgentCanvasViewAtom 主要选中节点/设置工作台或暂存 LOAD 后的意图，并不负责统一打开、切换具体画布标签和适配分屏焦点。
- CanvasChangeEvent 已有可选 source(sessionId/runStartedAt/toolCallId)，但没有统一变更节点、动作、内容版本；无来源事件也会用于人工编辑/旧生图。全量变化事件不能直接充当自动导航触发器。

## 已实施方案

1. UI 移除默认星标及“设为默认”。手动打开画布优先恢复当前会话最后查看的有效关联画布；没有可恢复项时显示画布列表/空状态，不静默挑另一会话的画布。
2. 写入目标依次由用户明确引用、本任务绑定、发送时确认的活动画布确定；多图歧义时询问。已启动任务固定真实目标，自动展示或手工切换标签不能将其后续写入改派。
3. 统一消费可校验的修改回执：发起会话/运行、项目、画布、节点或节点集合、动作、相关版本和去重身份。尽量扩展已有 source 与正式工具结果，而不是按标题或模型文字猜目标；覆盖文档/网页、媒体配置与采用、节点与连线和编排产生的明确写入。
4. 当前聊天的首个已确认修改，自动打开其具体 canvas tab，定位并高亮受影响节点；单节点可以打开对应工作台，批量修改展示变更摘要及节点列表。生成受理/进行中与结果已产出分别显示，不把提交当完成。
5. 同一批修改合并导航；用户主动切走、拖动画布或正在编辑未保存内容时，保留修改提示和“查看位置”入口，不持续夺取焦点。其它聊天/后台任务只更新所属聊天的修改摘要，不强制切换会话。只读查询、进度心跳与失败请求不伪装成成功修改导航。
6. “对应记录页面”优先复用具体画布 + 节点详情/已有版本或运行记录；不为这一需求额外创建一个脱离实际节点的记录系统。删除节点后展示删除摘要与所属画布，不导航不存在节点。

旧 binding 的 defaultCanvasId 暂保留为兼容字段，避免一次删除破坏首次关联、删除/归档回退和任务恢复；新界面入口优先最近查看，核心写工具继续强制显式 canvasId。自动展示不修改 default，且不能改变在途任务目标。历史画布、节点、素材与运行记录保留。移除默认按钮与路由调整应一起验证。导航仅更新会话视图，不产生画布业务 mutation、不额外生成内容；按事件去重和合并，不新增轮询或全图媒体读取。

## 验证边界

已验证范围包含当前/后台会话、分屏、首次打开/重启恢复、旧 binding、多画布歧义、单节点/批量/删除、异步子 Agent、失败/重复/迟到事件、用户主动切换及未保存草稿。


## 最终边界与证据

- UI 去除默认操作；主进程旧 default 字段/API 保留兼容。手动入口仅恢复仍有效的最近关联画布，否则打开列表；已有持久标签及主动关闭规则继续沿用。
- 在生产 createRun 准备阶段捕获本轮隐式目标；写工具仍需显式 canvasId 与独立授权。多图引用不隐式猜选，原目标解绑后不跳到新活动图。
- 使用正式工具结果内的 navigation 签发项目、画布、节点/删除集合、图版本及操作身份。委托归属由 Host 按真实编排记录在提交后复验，不能由模型参数指定；子 Agent 回执仅更新父聊天摘要。
- 本轮首次成功修改可自动打开具体标签，等权威 LOAD 后定位；后续合并为“查看位置”和节点按钮。删除仅定位所属画布；不新增独立历史页面。
- 手动切走、手势和草稿优先；显式点击允许同次外部点击关闭旧详情，仍取消验权等待期间的选区/视口变化，防止错误拦截与迟到抢焦点。
- 摘要是进程内有界缓存，最多 64 图、当前聊天显示 8 图，每图至多 512 个节点入口；重启后的业务历史仍从原节点记录查看。超限正式回执不触发摘要，不扩张为全图记录系统。
- 556 项相关测试通过，7 个 workspace 类型检查通过，最后增量 Electron 类型检查通过，主进程/Renderer 隔离构建通过，真实 Electron 内存画布验证通过。详细证据见 `.omx/reports/2026-09-16-canvas-change-navigation.md`。
