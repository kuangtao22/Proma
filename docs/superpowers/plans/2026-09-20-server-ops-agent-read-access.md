# 运维 Agent 第一批：多连接只读授权

> 用户已批准实施。使用现有 Pi Agent、运维服务和 JSON 审计，不引入依赖，不访问真实远程资源。

## 目标与边界

项目作为批量选择入口，授权固定到具体连接 ID。保留单 SSH 操作授权，新增多连接只读授权，两模式互斥。普通顶层用户会话可使用；自动化、委派、隐藏内部会话不可继承。授权仅保存在主进程内存，切换/删除会话、撤销、连接失效或应用退出及时清除；读取前后检查同一 revision 与连接配置身份。

MySQL 实例诊断与数据库授权分开，库范围明确列出库名、表白名单（null 表示该库全部表）及行读取许可。仅全部表范围可读取库级会话/语句分析，SQL 正文不传给模型；选表范围只开放结构和已授权的行。Redis 仅实例 INFO / SLOWLOG 指标，命令参数不返回。SSH 第一批开放已连接服务器概览与服务列表，连接和指纹确认继续使用界面。跳板授权不授予 SSH 命令权限。

连接改名/移动不影响身份；地址、端口、账号、引擎、TLS、默认库或跳板身份改变则失效。结果使用严格公开投影和 UTF-8 JSON 预算（32 KiB），行每次最多 50 条，默认遮罩常见敏感列。遮罩不是完整敏感数据识别，UI 明示所选数据会发送给模型。没有任意 SQL、命令、密码读取接口。

## 实施顺序

1. [x] 共享合同与授权 Store：严格解析、上限、深复制、revision、互斥、撤销和生命周期 BDD。

4. [x] 四层 IPC 与生命周期：shared/main/preload/renderer，普通会话检查、广播、保存/删除连接失效、会话切换与 context 释放。
5. [x] 项目授权弹窗：按连接选择，数据库/表/实例/行读取独立设置，明确当前范围与撤销；沿用 Proma Dialog、按钮和主题，无后台轮询。
6. [x] 独立规格审查、质量审查、最小行为测试、运维回归、类型检查、构建、隔离 UI 验收；回写 MEMORY。

## 验收

使用内存连接与假 runtime，不读取用户真实凭据/数据库。证明错会话、未授权资源、库表越界、实例权限缺失均在调用服务之前拒绝；撤销/重新授权/端点变化阻止旧结果；项目移动保持授权；无法用只读授权调用旧写工具；目录不泄漏其他库表。审计先写失败零读取，后写失败返回稳定警告。Pi 工具确实进入普通 Agent 的受控执行链，内部运行不注册。验证没有新增后台轮询或全库预载。

已知全仓基线：shared 的 canvas-media-model-scope.test.ts 有两处既有 readonly 类型错误，验证时单独报告，不改无关文件。

## 实施结果与验证（2026-09-20）

- 项目工具栏新增「授权给当前 Agent」，可跨项目保留已授权连接；实例、明确库名、全部表/指定表以及行读取分别设置。保存失败保留草稿，取消恢复已保存内容，撤销与切换会话会丢弃过期回执。旧单服务器操作授权继续保留，两种授权互斥。
- 普通顶层交互会话注册八个 `ops_*` 窄工具，经过既有 Pi permission wrapper 再进入只读 Facade；内部会话、自动化、委派和外部渠道不注册。旧 SSH 高风险操作仍走原逐次审批。组合行为测试实际执行 Pi 工具 → Facade → 真实 AccessStore/身份捕获 → 内存数据服务 → 严格审计合同，证明允许白名单、提前拒绝越界、屏蔽敏感列及丢弃撤权后迟到数据。
- 共享审计升级到 v4，严格兼容 v1/v2/v3；每次读取的开始与结果共享 operationId，按动作强制主机/实例/数据库/表范围。不保存结果值、凭据、SQL 或错误正文。审计和 Facade 的交叉复审补齐了关联 ID、库表长度与动作范围矩阵。

## 本批保留边界

SQL 执行、Redis 键浏览、配置写入和自动化授权属于后续批次。SSH 只读概览/服务依赖界面已连接；数据库语句分析仍为摘要且移除原始 SQL，Redis 只返回诊断指标。敏感列名遮罩是辅助保护，不能声称完整匿名化。密码经现有 IPC 修改时主动撤权，未来新增凭据修改入口也必须接入这一规则。权限不落盘，不新增后台轮询、全库预载或依赖；只读授权总大小最多 16 KiB，工具结果最多 32 KiB，单次行读取最多 50 行。现有审计视图可筛选 Agent 只读记录，本批未新增独立数据库审计页面。
