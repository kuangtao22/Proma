## 设计与影响

- 顶部采用「服务器运维」标题与项目切换按钮，下面放 Agent 提示条；提示只描述已授权能力。
- 搜索框与「Agent 只读授权 / 添加连接」组成工具栏，保留类型筛选和真实连接数量。
- 服务器、数据库、Redis 以非空可折叠分组显示，空类型只有筛选计数，不增加空占位。搜索或切换类型时重新展开当前结果。
- 卡片采用 Skills 页的圆角、细边框、图标、名称与信息层级；仍能辨认地址、SSH 连接状态和内网明文标记，管理菜单与进入连接独立操作。
- 按容器宽度显示一列、两列；1120px 及以上三列。所有局部断点只影响项目页，窄面板工具栏可换行。
- 只在内存中筛选和折叠，不增加 IPC、依赖、轮询或持久化写入。
