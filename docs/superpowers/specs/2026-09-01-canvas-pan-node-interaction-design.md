# Canvas 手型模式节点交互设计

## 目标

手型模式只改变画布的平移方式，不应让节点失去基本访问能力。用户在手型模式下单击节点可选中，双击节点可打开详情；拖动画布空白区域继续平移，节点本身保持不可拖动。

## 交互规则

- 选择模式：维持现有行为，节点可选择、拖动、连线和框选。
- 手型模式：所有节点仍可选择；单击只选中，双击选中并打开节点工作台。
- 手型模式下 `nodesDraggable` 和 `nodesConnectable` 保持关闭，避免平移操作误改图结构。
- 手型模式下点击空白区域不清除现有选区，避免结束平移时丢失当前上下文。
- 画布平移仍由 XYFlow 的 `panOnDrag` 处理，不增加自定义指针手势或距离阈值。

## 实现边界

修改 `NativeCanvasGraph`：

1. 节点可选择性不再依赖当前工具。
2. 节点单击和双击回调不再拒绝手型模式。
3. 节点拖动、连线、框选和空白区域清除选区继续只在选择模式生效。

不修改 Workspace 状态模型、Canvas 文档、持久化 mutation、节点卡片或工作台组件。

## 关联影响

- 选择模式行为保持不变。
- 手型模式不会产生节点移动或连线 mutation。
- Agent、生图、文档和 WebView 节点共用同一 Graph 事件，因此四类节点行为一致。
- 工作台仍遵循单击不展开、双击展开的既有约定。

## 性能

只调整 XYFlow 布尔属性与两个事件守卫，不新增状态、监听器、渲染层或 I/O，时间和内存开销为常数级。

## 验证

- BDD 测试证明手型模式下 `elementsSelectable=true`、`nodesDraggable=false`、`panOnDrag=true`。
- 模拟手型模式节点单击，验证完整选区更新且不打开详情。
- 模拟手型模式节点双击，验证选区更新并打开对应工作台。
- 验证选择模式的节点拖动和手型模式的零移动 mutation 边界不回退。
