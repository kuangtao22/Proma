# 运维服务器凭据配置设计

日期：2026-09-05

## 结论

服务器密码、私钥路径和私钥口令在“添加/编辑服务器”弹窗中配置，并随“保存服务器”动作默认持久化。保存成功后的“连接”按钮直接使用主进程中的安全凭据；只有凭据缺失、无法读取或认证失败时，才打开临时登录弹窗补录。

界面沿用 LLM 渠道配置的用户心智：配置实体时一并配置认证信息，编辑时能识别已有凭据并选择保留、替换或清除。但安全实现不复制 LLM 渠道在 `safeStorage` 不可用时降级为明文的行为，服务器凭据始终 fail closed。

## 用户流程

1. 新建服务器时，选择“密码”会显示密码输入框；选择“私钥文件”会显示私钥路径和可选口令；选择“SSH Agent”不显示秘密字段。
2. 密码或私钥认证的新服务器必须提供凭据才能保存；凭据由主进程使用 Electron `safeStorage` 加密。
3. 编辑已有密码或私钥服务器时，默认展示“凭据已保存”，不把明文回填 Renderer；用户可选择“替换凭据”或“清除凭据”。
4. 编辑其它公开字段且不操作凭据时，旧凭据保持不变。
5. 切换认证方式时，旧认证凭据失效：切换到密码或私钥必须录入新凭据，切换到 SSH Agent 会清除旧凭据。
6. 点击“连接”时，有已保存凭据或使用 SSH Agent 的服务器直接连接；缺少凭据时才打开登录弹窗。
7. 直接连接若返回凭据缺失、私钥不可读或认证失败，打开登录弹窗并展示公开错误；Host Key 首次确认与变化阻断流程保持不变。

## 数据与安全边界

- `~/.proma/server-ops/hosts.json` 继续只保存名称、地址、端口、用户名、认证方式、标签、时间戳和非敏感 `credentialRef`。
- `~/.proma/server-ops/credentials.json` 继续只保存版本化的 `safeStorage` 密文。
- Renderer 只能在保存或临时连接请求中短暂持有用户正在输入的秘密；凭据不进入 Jotai、localStorage、日志、Toast、公开错误或公开主机 DTO。
- 编辑页面不主动解密并回填密码或私钥口令，只返回 `credentialRef` 所代表的“已配置”状态。
- Linux `basic_text`、加密不可用或解密失败均不得降级为明文。

## IPC 合同

主机资产字段与凭据变更分开建模。`ServerOpsSaveHostInput` 包含：

- `host`：现有 `ServerOpsUpsertHostInput`，不允许秘密字段。
- `credentialUpdate`：`keep`、`replace` 或 `clear`。

`replace` 只接受与 `host.authMethod` 一致的密码或私钥配置；SSH Agent 只能使用 `clear`。新建密码/私钥主机不允许 `keep`，认证方式变化时也不允许保留旧凭据。

主进程 IPC registrar 是组合保存的唯一授权边界：先写入严格解析的主机资产，再保存、绑定或清除凭据。失败时以不泄露秘密的稳定错误返回，公开 DTO 始终只返回 `ServerOpsHost`。

## UI 结构

弹窗继续复用现有 Radix/shadcn `Dialog`、`Input`、`Select` 和主题变量，不新增卡片嵌套或独立配色。

- 基础信息：名称、地址、端口、用户名。
- 认证信息：认证方式及其条件字段。
- 组织信息：标签。
- 已保存凭据采用紧凑的边框提示行和图标状态；“替换凭据”为次要按钮，“清除凭据”为危险文字按钮。
- 保存中禁用关闭和提交；字段错误在认证组附近展示；保存成功继续使用现有 Toast。
- 密码字段使用 `password` 类型与 `new-password` 自动完成语义，私钥口令不主动回填。

## 关联影响

- Agent、Canvas、LLM 渠道、数据库/Redis 页面和本地 Terminal 不变。
- 现有临时登录弹窗保留，职责收窄为异常补录，不再是正常连接的必经步骤。
- 现有已保存凭据无需迁移；已有未保存凭据的主机在首次连接或编辑时补录。
- Host Key 信任、SSH utility process 和 PTY 协议不变。

## 性能与资源

保存密码或私钥时增加一次 `safeStorage` 加密和一次小型凭据 JSON 原子写；公开主机文件仍为一次小型原子写。连接阶段减少一次弹窗交互，不增加轮询、后台进程或常驻连接。

## 验收条件

- 新建密码和私钥服务器时可在同一弹窗录入并安全保存凭据。
- 编辑时能保留、替换和清除凭据，且不回填明文。
- SSH Agent 不展示或接受秘密字段。
- 正常“连接”不再打开登录弹窗，缺少或失效凭据时才回退补录。
- `hosts.json`、公开 DTO、日志和错误信息不包含密码、私钥路径、私钥口令或私钥内容。
- Linux 不安全 backend 拒绝保存且不产生明文文件。
- 共享合同、IPC、主进程存储编排和 Renderer 表单都有 BDD 风格测试。
