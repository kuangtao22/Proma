## 更新内容

- 修复 Windows 覆盖安装或迁移数据目录后，目录持久化能力受限导致渠道创建失败的问题。
- 渠道配置迁移回写失败时继续保留并展示原有模型；配置损坏时停止自动写入预设，避免把读取失败误判为没有模型。
- 模型设置页加载失败时保留上一次成功的渠道列表，并展示真实错误和重试入口。
- 修正 GitHub Actions 对 macOS 签名条件的判断；配置证书时正常签名，未配置时明确生成未签名安装包。

## macOS 未签名版本安装

当前 Bone macOS 安装包可能未签名。请只从本仓库 GitHub Release 下载，然后在终端执行：

```bash
xattr -cr ~/Downloads/Proma-0.17.55-bone.3-macos-*.dmg
open ~/Downloads/Proma-0.17.55-bone.3-macos-*.dmg
```

将 Proma 拖入“应用程序”后，再执行：

```bash
sudo xattr -cr /Applications/Proma.app
open /Applications/Proma.app
```

`xattr` 会移除 macOS 的下载隔离标记；这不等同于 Apple 代码签名或公证。
