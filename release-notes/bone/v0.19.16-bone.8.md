## 重点更新

### 全新原生画布工作区

- 新增项目级多画布工作区，可在侧栏创建、切换、归档和恢复 Canvas。
- 支持在画布中组织 Agent、文档、WebView 和图片等多类型节点，并通过连线表达引用、依赖和衍生关系。
- 支持节点内独立工作台、详情浮层、平移/缩放、触控板手势、紧凑布局及运行状态展示。
- 可从 Agent 对话引用画布节点，也可由 Agent 创建和更新画布产物，让对话、规划与可视化交付保持联动。

### Canvas Production 内置 Skill

- 新增 `canvas-production` 默认 Skill，可根据任务语义规划画布节点和关系。
- 支持网页原型、图片设计稿、产品套图、漫剧分镜、文档和程序规划等多产物工作流。
- Agent 可读取已有画布上下文，局部更新文档、WebView 或图片提示词，并保留稳定节点与版本历史。
- 明确区分画布生产与普通代码修改，避免不必要地把一次性任务转入画布。

### 图片生产与版本验收

- 增加 Canvas 图片工作台，支持图片比例、模型参数、参考素材和项目创作上下文。
- 图片生成结果先进入候选批次，可对比、采用或保留旧版本，不再直接覆盖当前正式图片。
- 支持批量核对画布图片的一致性，并按节点定位需要调整的视觉内容。
- 完善图片任务恢复、超时处理、状态同步和媒体生命周期。

### 文档与 WebView 产物

- 文档节点支持 Markdown 内容编辑和版本历史。
- WebView 节点支持完整 HTML 预览、桌面/手机设备比例切换以及独立工作台。
- 产物采用原子创建与可恢复存储，异常退出后可重建未完成的内容事务。

### Agent 编排与可靠性

- 支持在 Canvas 内创建和运行受控 Agent 节点，并持久化节点与会话的关联关系。
- 支持节点引用进入 Agent 消息、基于既有产物继续衍生，以及节点和连线的原子批量提交。
- 增加运行审批、幂等屏障、并发写保护、恢复对账和故障节点重建。

## 其他 Bone 功能

- 增强局域网移动端：扫码配对、可信设备管理、会话状态同步与星标。
- 增加 Proma 业务数据目录管理、项目路径迁移、中断恢复和完整性校验。
- 增加图片生成模型配置与 GPT Image 2 支持。
- 增加 Bone/官方双来源版本历史和独立的开发版/正式版身份。

## 修复与兼容性

- 修复 Windows Canvas 内容和 intent 原子提交失败；相对重命名始终绑定已授权目录句柄，避免路径重解析和 TOCTOU 风险。
- Windows 覆盖已有文件时使用 `FileRenameInformationEx`，稳定目录 helper 的真实 Windows 回归测试已全部通过。
- 完善 Windows 原生 helper 构建、Linux 打包元数据及多平台 Release 工作流。
- 同步官方 Proma `v0.19.16` 的功能与修复。

## macOS 未签名版本安装

当前 Bone macOS 安装包可能未签名。请只从本仓库 GitHub Release 下载，然后在终端执行：

```bash
xattr -cr ~/Downloads/Proma-0.19.16-bone.8-macos-*.dmg
open ~/Downloads/Proma-0.19.16-bone.8-macos-*.dmg
```

将 Proma 拖入“应用程序”后，再执行：

```bash
sudo xattr -cr /Applications/Proma.app
open /Applications/Proma.app
```

`xattr` 会移除 macOS 的下载隔离标记；这不等同于 Apple 代码签名或公证。
