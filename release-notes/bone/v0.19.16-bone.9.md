## 更新内容

### 画布 WebView 预览修复

- 修复画布原型工作台在“预览”模式下仍叠加显示 HTML 源码的问题。
- 预览、HTML 编辑和版本面板现在使用显式且互斥的显示状态，不再受浏览器原生 `hidden` 样式优先级影响。
- 切换工作台模式时保留 iframe，不会重建正在预览的原型或丢失页面内部状态。

## macOS 未签名版本安装

当前 Bone macOS 安装包可能未签名。请只从本仓库 GitHub Release 下载，然后在终端执行：

```bash
xattr -cr ~/Downloads/Proma-0.19.16-bone.9-macos-*.dmg
open ~/Downloads/Proma-0.19.16-bone.9-macos-*.dmg
```

将 Proma 拖入“应用程序”后，再执行：

```bash
sudo xattr -cr /Applications/Proma.app
open /Applications/Proma.app
```

`xattr` 会移除 macOS 的下载隔离标记；这不等同于 Apple 代码签名或公证。
