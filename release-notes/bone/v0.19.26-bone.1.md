## 更新内容

### 同步 Proma 0.19.26

- 合入官方 `v0.19.26` 的 Agent、Vault、Browser、MCP 和文件面板改进。
- 保留 Proma Bone 的画布、移动端、数据目录与内部会话隔离能力。

### 画布工作流升级

- 画布统一进入普通 Agent 的右侧工作区，支持按项目管理多张画布、切换、新建、重命名、归档和删除。
- 画布默认按需打开，并按会话恢复上次实际打开的画布；后台生成不会抢占当前工作区。
- 支持 Agent、图片、文档与 WebView 节点，以及关联、引用、依赖和衍生关系；Agent 可通过 Canvas 工具编排专业 Skills 和多节点生产流程。
- 图片节点统一从历史版本中预览并“设为默认”，卡片展示、下游引用和实际采用版本保持一致。
- 节点详情会随画布平移、缩放和节点拖动实时跟随，同时保持固定屏幕尺寸。
- 重新排版按图片比例与 WebView 设备预设的当前卡片尺寸计算，减少节点重叠。
- 修复画布展开后的边界线穿透，并兼容 macOS 原生窗口按钮和 Windows 自绘标题栏。
- 修复 Canvas 引用发送失败无反馈、跨客户端关联读取过期和批量生图事务 ID 不兼容等问题。

### Linux 服务器运维工作台

- 在 Agent 右侧新增可关闭的“运维”工作区，可维护和切换 Linux SSH 主机。
- 支持密码、私钥与 SSH Agent 登录，并提供真实可交互的远程终端。
- 首次连接必须确认 Host Key 指纹；服务器指纹变化时直接阻断连接。
- 密码默认只保留在当前应用进程，选择记住后使用 Electron `safeStorage` 加密；公开主机配置不保存密码、私钥路径或 passphrase。
- SSH 运行在独立 utility process，终端输出包含背压和缓存上限，关闭应用时会释放连接资源。
- 服务、日志、文件、Docker、数据服务和审计页已保留稳定入口，远程数据能力将在后续版本逐步接入。

- **Linux x64**：`.AppImage` 或 `.deb`

## macOS 未签名版本安装

当前 Bone macOS 安装包可能未签名。请只从本仓库 GitHub Release 下载，然后在终端执行：

```bash
xattr -cr ~/Downloads/Proma-0.19.26-bone.1-macos-*.dmg
open ~/Downloads/Proma-0.19.26-bone.1-macos-*.dmg
```

将 Proma 拖入“应用程序”后，再执行：

```bash
sudo xattr -cr /Applications/Proma.app
open /Applications/Proma.app
```

`xattr` 会移除 macOS 的下载隔离标记；这不等同于 Apple 代码签名或公证。
