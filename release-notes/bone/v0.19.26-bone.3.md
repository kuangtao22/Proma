## 更新内容

### Linux 服务器运维控制台

- 在 Agent 右侧提供独立运维工作区，可维护和切换 Linux SSH 主机，并使用密码、私钥或系统 SSH Agent 连接。
- 密码和私钥口令通过 Electron `safeStorage` 加密保存；公开主机配置、日志和错误信息不包含凭据。
- 新增真实主机概览，展示 CPU、内存、负载、磁盘、网络和运行时间；只在概览可见时刷新。
- 新增 systemd 服务列表、详情与启动、停止、重启、启用、禁用操作，所有变更动作均需确认并写入审计。
- 新增 journal 实时日志，支持远程筛选、本地搜索和暂停；切换服务器或页面时会关闭旧日志流。
- Agent 可在当前会话授权范围内调用连接、状态、命令和断开等运维方法；授权随会话切换、断线或 runtime 退出自动撤销。
- Agent 远程操作写入本地审计记录，并对命令中的密码、Token、Authorization、URI 凭据和私钥路径进行脱敏。

### Canvas Agent 自动工作流

- Canvas Agent 可独立配置职责、Skills 和模型，普通 Agent 可启动单个节点或运行指定起点的有界工作流。
- 工作流只沿已确认的可执行依赖推进，并限制节点数、并发数、图片数量、深度和总运行时间。
- Agent 正式输出以稳定指针进入画布，下游只读取已提交产物；失败分支不会阻断无关分支。
- 图片节点支持批次启动、精确取消、逐节点结果和候选验收，采用默认版本后才继续下游。
- 普通 Agent 与 Canvas Agent 均可受控修改图片提示词、模型、画幅、尺寸和上下文配置，不会直接触发付费生成。
- 修复带可信 Canvas 参考图的自动上下文准入，并在任务详情中展示实际图片模型，而不是内部兼容工具名。

### 稳定性与安装体验

- Windows 原位升级安装前展示旧版本、旧安装目录和本次目标目录，首次安装流程保持不变。
- 修复 Windows 卸载器编译时误包含升级摘要页函数的问题，恢复完整安装包生成。
- 收紧 Windows Canvas 稳定目录 helper 的根目录权限，提升受限 ACL 和企业目录环境的兼容性。
- 修复 Agent Island 远期提醒的超长定时器溢出，避免远期待办造成高频调度。

## macOS 未签名版本安装

当前 Bone macOS 安装包可能未签名。请只从本仓库 GitHub Release 下载，然后在终端执行：

```bash
xattr -cr ~/Downloads/Proma-0.19.26-bone.3-macos-*.dmg
open ~/Downloads/Proma-0.19.26-bone.3-macos-*.dmg
```

将 Proma 拖入“应用程序”后，再执行：

```bash
sudo xattr -cr /Applications/Proma.app
open /Applications/Proma.app
```

`xattr` 会移除 macOS 的下载隔离标记；这不等同于 Apple 代码签名或公证。
