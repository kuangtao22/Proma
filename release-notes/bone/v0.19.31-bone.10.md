## 更新内容

### Canvas Agent 操作补齐

- 支持在原对话中查看候选图片，区分“尚未生成”和“已生成未采用”；查看候选不会自动采用或重新生成。
- 修复批量生图等待用户审批时提前超时，以及重新打开画布后的图片采用恢复问题。
- 新增任务详情、取消、按原快照重试，支持查看历史版本、采用精确版本和整批采用候选。
- 支持查询、继续和取消持久工作流；恢复时核对原任务与输出，只推进输入仍有效的未完成节点，避免重复执行已完成步骤。
- 支持单项和批量导出精确版本的图片、文档及 WebView 产物，以及回收内容恢复和损坏 Agent 节点重建。
- 默认 `canvas-production` Skill 升级至 `1.0.10`，可发现的操作与当前 Agent 模式、权限保持一致。

### 多图与大画布性能

- 合并密集任务事件，复用未变化的节点对象，并按可见区域渲染，减少多图生成时的整图刷新。
- 图片活动改用增量任务索引和精简摘要，后台刷新失败时保留已有内容。
- 完成的恢复事务按固定预算归档，避免长期使用后累计历史占满活动事务容量。
- 工作流历史分页限制内存占用；历史目录仍按需扫描，尚未增加索引。

### Windows 启动与打包

- 修复自定义数据根离线或路径失效时，应用在恢复界面出现前退出的问题。
- 修复 Windows 安装包遗漏 Sharp 原生依赖的问题；打包前显式安装并校验 Windows x64 运行时。
- 修复 Windows 画布事务读取原生代码的编译错误，并保留完整编译诊断。
- 原生测试的编译准备使用独立两分钟期限，避免共享 CI 机器负载较高时被旧的 30 秒初始化上限误判失败；各项行为测试继续使用原有超时。
- 保留 `.8`、`.9` 失败标签，不改写公开版本；延续官方 `v0.19.31` 基线以及现有 Slack Bridge、Server Ops、LAN Bridge 和本地业务配置。

## 验证与范围

- 已完成 Canvas 相关自动化回归、类型检查、Electron 构建和隔离环境下的 1000/3000 节点交互验证。
- 修复后的业务源码已通过独立 Windows 原生回归及安装包构建。
- 生产业务画布完整闭环、真实模型渠道调用及安装后使用仍需场景验证；此前源码启动自动化存在握手超时，未计为通过。
- 本次不包含 ComfyUI、视频和音频供应商接入；整批候选采用支持 `all/succeeded`，任意候选子集的原子采用尚未支持。

## macOS 未签名版本安装

当前 Bone macOS 安装包可能未签名。请只从本仓库 GitHub Release 下载，然后在终端执行：

```bash
xattr -cr ~/Downloads/Proma-0.19.31-bone.10-macos-*.dmg
open ~/Downloads/Proma-0.19.31-bone.10-macos-*.dmg
```

将 Proma 拖入“应用程序”后，再执行：

```bash
sudo xattr -cr /Applications/Proma.app
open /Applications/Proma.app
```

`xattr` 会移除 macOS 的下载隔离标记；这不等同于 Apple 代码签名或公证。
