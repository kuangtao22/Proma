## 更新内容

### 统一媒体配置与 ComfyUI

- 媒体配置统一为媒体模型、服务连接和公共工作流三个列表，采用独立添加、编辑和返回交互。
- 连接详情可查看模型、工作节点、工作流和资源库；模型按存放目录筛选，工作流完整 JSON 在只读代码编辑器弹窗中查看。
- 画布统一管理 ComfyUI 服务器与可用 API 模型范围，Agent 可发现、分析并导入服务器上的工作流。
- 节点、模型和工作流目录支持本地快照及显式同步，减少重复拉取；工作流运行继续校验精确连接身份、模板版本和输入映射。
- 补齐可证明的 ComfyUI UI 工作流序列化兼容；不支持或不一致的节点定义会返回具体节点、字段和原因。

### 先建卡片，再配置生成

- 图片、音频和视频先创建目标卡片，再绑定工作流和填写真实输入参数；支持保存部分配置、展示缺失字段和准备错误。
- 修复创建音视频卡片时报 `CANVAS_CONTENT_KIND_INVALID`，同时修复空正文被拒绝及重复准备误走 WebView 校验的问题。
- 重试保留原媒体配置；已提交配置损坏时明确报错，不自动重建覆盖。
- 媒体任务进度、诊断与候选结果留在对应卡片，运行恢复按原任务身份对账。

### 画布交互与服务器运维

- 画布详情跟随所属卡片定位，支持外部点击关闭；优化拖动、缩放和关联层级整理。
- 修复工作台重复发布无变化状态导致的 React 更新循环与卡顿。
- 合入服务器运维模块，完善连接信任恢复、文件传输与 Docker 管理。

## macOS 未签名版本安装

当前 Bone macOS 安装包可能未签名。请只从本仓库 GitHub Release 下载，然后在终端执行：

```bash
xattr -cr ~/Downloads/Proma-0.19.31-bone.11-macos-*.dmg
open ~/Downloads/Proma-0.19.31-bone.11-macos-*.dmg
```

将 Proma 拖入“应用程序”后，再执行：

```bash
sudo xattr -cr /Applications/Proma.app
open /Applications/Proma.app
```

`xattr` 会移除 macOS 的下载隔离标记；这不等同于 Apple 代码签名或公证。
