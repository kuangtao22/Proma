## 更新内容

### 同步 Proma 0.19.31

- 合入官方 `v0.19.31` 的功能与修复，并将 Pi Agent Runtime 升级到 `0.85.0`。
- 新增 Slack Bridge，可在机器人中心配置 Slack App，并通过 Socket Mode 与 Proma Agent 对话。
- 新增 GPT-6 Astra 模型识别与图标，并适配 Gemini 3 系列的思考深度。
- 优化折叠侧栏，在紧凑模式下仍可快速切换会话、协作 Agent 和工具。
- 保留项目与会话附加目录的展开状态，改善文件浏览连续性。
- 优化响应式搜索弹窗，并修复部分 Google 页面被浏览器控制器过早关闭的问题。
- 删除 MCP Server 时保留其他服务的启用状态，避免无关配置被重置。

### Bone 能力与安全边界

- 保留 Canvas、Linux SSH Server Ops、LAN Bridge、共享业务数据目录和内部会话隔离能力。
- Design 内部生图继续使用受限工具集合，避免 Workspace Skills 或无关工具进入图片执行上下文。
- MCP 删除操作新增工作区写守卫并使用原子配置写入，迁移中、未知或非法工作区会在副作用前被拒绝。
- Agent 完成事件复用启动时的权威运行代次，避免迟到事件覆盖新一轮运行状态。
- 修复干净 Bun workspace 中 EventKit 原生构建依赖路径，开发态 Electron 权限注入不再依赖历史 hoist 结果。

### 发布修复

- 调整 `node-pty` 原生模块重建与运行时依赖同步顺序，避免干净 Bun workspace 清理本地构建工具后导致跨平台打包失败。
- 增加发布合同测试与 fork 兼容检查，后续合并官方代码时会持续校验该构建顺序。

## macOS 未签名版本安装

当前 Bone macOS 安装包可能未签名。请只从本仓库 GitHub Release 下载，然后在终端执行：

```bash
xattr -cr ~/Downloads/Proma-0.19.31-bone.2-macos-*.dmg
open ~/Downloads/Proma-0.19.31-bone.2-macos-*.dmg
```

将 Proma 拖入“应用程序”后，再执行：

```bash
sudo xattr -cr /Applications/Proma.app
open /Applications/Proma.app
```

`xattr` 会移除 macOS 的下载隔离标记；这不等同于 Apple 代码签名或公证。
