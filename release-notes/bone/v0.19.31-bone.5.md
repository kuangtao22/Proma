## 更新内容

### 同步 Proma 0.19.31

- 合入官方 `v0.19.31` 的功能与修复，并将 Pi Agent Runtime 升级到 `0.85.0`。
- 新增 Slack Bridge、GPT-6 Astra 模型识别、Gemini 3 思考深度适配和响应式搜索弹窗。
- 保留 Canvas、Linux SSH Server Ops、LAN Bridge、共享业务数据目录和内部会话隔离能力。
- 修复 MCP 删除边界、Agent 完成事件运行代次以及 EventKit 原生构建依赖路径。

### 发布修复

- 固定 Electron Builder 为经过验证的 `25.1.8`，macOS、Windows、Linux 与本地打包入口不再下载不兼容的新版本。
- Windows 原生 helper 回归在整理运行时依赖之前执行，避免测试所需的 Electron 开发依赖被提前清理。
- 发布流水线固定使用 Bun `1.3.14`，并显式安装 `node-gyp@12.4.0`，避免 `node-pty` 安装阶段临时下载损坏或不兼容的最新构建工具。
- 保留 `v0.19.31-bone.1` 至 `v0.19.31-bone.4` 失败标签，不移动已经公开的发布引用。

## macOS 未签名版本安装

当前 Bone macOS 安装包可能未签名。请只从本仓库 GitHub Release 下载，然后在终端执行：

```bash
xattr -cr ~/Downloads/Proma-0.19.31-bone.5-macos-*.dmg
open ~/Downloads/Proma-0.19.31-bone.5-macos-*.dmg
```

将 Proma 拖入“应用程序”后，再执行：

```bash
sudo xattr -cr /Applications/Proma.app
open /Applications/Proma.app
```

`xattr` 会移除 macOS 的下载隔离标记；这不等同于 Apple 代码签名或公证。
