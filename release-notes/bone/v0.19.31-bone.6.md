## 更新内容

### Windows 启动恢复修复

- 修复自定义数据根所在磁盘离线、盘符变化或定位文件失效时，Windows 主进程在启动阶段直接报“数据根不可用”的问题。
- Agent-Canvas 关联存储改为在数据根通过 normal gate 后初始化，不再由静态模块加载提前触发业务目录访问。
- 数据根不可用时恢复原有路径管理界面；正常数据根下的 Agent、Canvas 关联和服务器运维功能保持不变。
- 新增启动隔离回归测试，后续打包前会自动阻止同类业务 Store 越过数据根启动门。

## macOS 未签名版本安装

当前 Bone macOS 安装包可能未签名。请只从本仓库 GitHub Release 下载，然后在终端执行：

```bash
xattr -cr ~/Downloads/Proma-0.19.31-bone.6-macos-*.dmg
open ~/Downloads/Proma-0.19.31-bone.6-macos-*.dmg
```

将 Proma 拖入“应用程序”后，再执行：

```bash
sudo xattr -cr /Applications/Proma.app
open /Applications/Proma.app
```

`xattr` 会移除 macOS 的下载隔离标记；这不等同于 Apple 代码签名或公证。
