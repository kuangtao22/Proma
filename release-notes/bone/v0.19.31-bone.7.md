## 更新内容

### Windows 启动与跨平台打包修复

- 修复自定义数据根所在磁盘离线、盘符变化或定位文件失效时，Windows 主进程在恢复界面出现前直接退出的问题。
- 修复在 macOS 上构建 Windows x64 安装包时遗漏 `sharp` 的 Windows 原生运行时，导致安装后启动报错的问题。
- Windows 打包现在会显式安装目标平台依赖，并在生成安装包前强制校验 `@img/sharp-win32-x64`；缺失时构建会直接失败，不再产出表面成功但无法启动的安装包。
- 正常数据根下的 Agent、Canvas、图片处理和服务器运维功能保持不变。

## 下载

- **Windows x64**：`.exe`
- **macOS Apple Silicon**：`macos-arm64.dmg`
- **macOS Intel**：`macos-x64.dmg`
- **Linux x64**：`.AppImage` 或 `.deb`

## macOS 未签名版本安装

当前 Bone macOS 安装包可能未签名。请只从本仓库 GitHub Release 下载，然后在终端执行：

```bash
xattr -cr ~/Downloads/Proma-0.19.31-bone.7-macos-*.dmg
open ~/Downloads/Proma-0.19.31-bone.7-macos-*.dmg
```

将 Proma 拖入“应用程序”后，再执行：

```bash
sudo xattr -cr /Applications/Proma.app
open /Applications/Proma.app
```

`xattr` 会移除 macOS 的下载隔离标记；这不等同于 Apple 代码签名或公证。
