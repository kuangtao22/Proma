## 更新内容

### 批量导入的接口更好用

- 保存接口或批量整理时，会明确提醒三类「难用」的写法：名字只是「方法 + 路径」（侧栏截断后看起来一模一样）、同一个主机被多条请求硬编码、JSON 正文是空对象 `{}`（参数其实没填）。提醒同时给 Agent 和你的确认卡，便于当场改掉。
- 集合菜单新增「主机提取为变量」：把集合同一主机抽成集合变量 `baseUrl`，命中的请求 URL 改成 `{{baseUrl}}/...`。
- 集合菜单新增「主机提取到环境」：把主机抽成**环境**变量并把这些请求绑定到该环境——「测试环境 = http://127.0.0.1:18080、生产环境 = https://...」这种切换从此只改一处；同名变量值不一致时会拒绝改写并说明原因。

### Agent 能整理存量接口（不再一条条弹窗）

- 新增「保存环境变量」：Agent 可以建/改测试、生产环境并声明 `baseUrl` 等变量；密钥类取值由主进程加密保存，确认卡只列变量名。
- 新增「批量整理接口」：一次确认最多改 50 条的名字、分组（模块文件夹）、所属集合（端 / 产品线）与环境绑定，一次原子落库；卡上逐条列出「从什么改成什么」。它不动 URL 与请求参数。
- 新增「剥离测试环境地址」：抽主机、改 URL、绑定环境由主机进程统一执行，Agent 不能自己拼地址；没有可抽取的主机时会在确认前拒绝。
- 由此，「把之前批量导入的接口分组、取名、剥离测试环境 IP」这三件事都可以让 Agent 一次做完（分几批确认）。

### 界面

- 新增「移动到其他分组 / 集合」：侧栏请求右键或编辑器工具栏都能打开对话框，目标集合与分组都从目录里选（支持集合根目录 / 已有分组 / 新建分组），原地不动时确认按钮不可点。
- 修复窄栏（工作台宽度较窄）下点「打开目录」时，目录会**跑到整个窗口最左侧并盖住全窗口**的问题；现在抽屉停在工作台这一栏内，Esc 或点遮罩可关闭。

### 稳定性与提示

- 修复「退出被取消后接口工作台与运维永久半死」：以前在「Agent 正在运行，确认退出吗」里点取消（或 macOS 只关窗口不退出），清理已经跑过而进程继续活着，之后打开接口只能看到 `API_WORKBENCH_SHUTTING_DOWN`，必须重启客户端；现在下 一次调用会自动重建服务并恢复可用。
- 接口面板的错误提示可读化：会话不适用时直接显示原因（例如「这是探索子会话；Agent 出网能力只在主会话开放」），客户端正在退出/需要重启时提示「请重启 Proma 后重试」，不再只给一个错误码。

## 升级说明

- 基于官方 `v0.19.53`，Bone 构建号递增为 `10`；提供 macOS Apple Silicon、macOS Intel、Windows x64 和 Linux x64 安装包。
- 接口资产按项目隔离；文件引用与 Cookie 只活在主进程内存，应用重启后需重新选择文件。
- 数据库访问继续默认只读。Agent 仅能读取会话已授权范围内、未禁用的业务表；不希望发送给模型的表，请先设置禁用。
- macOS 安装包沿用未签名分发。若系统提示应用已损坏，确认安装包来自本仓库后，将应用放入“应用程序”，再执行 `xattr -dr com.apple.quarantine /Applications/Proma.app`。
