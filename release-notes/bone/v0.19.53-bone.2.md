## 更新内容

### 图片输入与生成验收

- 图片节点支持明确选择编辑底图；指定参考节点时使用该节点的正式素材，减少旧版本图片意外参与新一轮生成的问题。
- 修复 GPT Image 多参考图只发送首张的问题，按顺序发送完整参考，并记录本地请求准备时的提示词和素材摘要，便于追溯输入。
- 新建原生 API 图片任务固定完整提示词与生成参数，避免内部规划再次改写关键约束；提示词超限明确报错，不静默截断。参数执行范围沿用各图片接口的现有支持。
- 修复新候选已生成并检查后仍无法完成任务的问题。生成检查、质量判断与正式采用分别处理，不需要为了完成检查而采用不合格图片。

### 导演评审与工作流恢复

- 根据任务用途、验收精度和实际可用能力组织制作流程。多镜头任务可先由导演专业节点规划镜头、转场、首尾状态及音视频资产，再按依赖推进。
- 专业节点支持明确的全图或局部审核范围，并返回实际读取覆盖情况；导演可前置布局，审核范围与生成依赖分别管理。
- 修复新建专业节点因尚无正式输出而无法读取配置的问题；移除单专业 Agent 调用固定 15 分钟中断，继续保留停止和取消控制。
- 失败回执提供实际执行节点、失败阶段和恢复方向，停用模型可在原节点修正，减少盲目重建与重复生成。
- 补齐原工作流的定向重试与预算恢复入口。现有自动模式下可在原预算内继续；追加生成次数或时长仍需确认，工作流图片不能通过独立重试绕过原预算。
- 内置制作规则升级至 `1.0.27`，要求按实际证据区分通过、不通过和无法验证，连续失败时重新检查输入、制作方式与验收方法。

### 性能与画布体验

- 展示历史不再重复携带未展示的内嵌图片数据；全局历史缓存增加容量预算，原始会话记录和模型读取内容保留。
- 已知生图任务的进度更新使用轻量状态，减少完整工作台重载；图片默认显示缩略图，打开大图时再加载原图。
- 统一右侧“画布”标签并记住会话打开状态，主动关闭后不自动恢复；新增节点关系搜索、定位和选中。
- 修复待配置视频节点误显示运行动画的问题，改善生成失败原因展示与 ComfyUI 节点配置兼容。

## 升级说明

- 基于官方 `v0.19.53`，Bone 构建号递增为 `2`；提供 macOS Apple Silicon、macOS Intel、Windows x64 和 Linux x64 安装包。
- 新生成任务使用新的输入合同；旧任务重试继续使用原快照。修改目标后，应保存节点配置并生成新候选。
- GPT Image 当前仍按画幅映射请求像素尺寸，界面的 1K/2K/4K 选择尚未参与该接口映射，本版未新增其 2K/4K 输出能力；请以实际产物尺寸为准。
- 审核覆盖和运行成功不等于内容质量合格；精确文字、尺寸、几何适配及视听连续性仍需按实际产物验收。
- 本版 macOS 安装包沿用未签名分发。若系统提示应用已损坏，确认安装包来自本仓库后，将应用放入“应用程序”，再执行 `xattr -dr com.apple.quarantine /Applications/Proma.app`。
