## 更新内容

### 画布专业工作流与聊天协作

- 聊天 Agent 传递目标和约束，由画布 Agent 按视频、UI、策划等任务自主规划专业阶段，分派子 Agent 完善成果并逐阶段评审；已有成果按变更影响范围复用。
- 补齐导演、脚本、镜头、美术、服装造型、场景道具、动作表演及摄影灯光的适用性判断与成果交接，减少只堆生成节点、设计输入缺失和镜头连续性问题。
- 聊天中可查看关联画布的实际阶段、阻塞与关键决策；回答前核对原问题，答案回到原委托继续处理，保留当前草稿、附件和引用，避免重复发送或串到其他画布。
- 后续需求校正保留原任务目标、交付约定和预算；上游变更使受影响的旧评审失效，待决策期间阻止业务推进，避免按过期方案继续生成。
- 修复新旧工作流竞争、异步写入与决策发布冲突、初始文档正文误判为空，以及加载失败时错误提示被隐藏等问题。

### 画布查找、平移与素材展示

- 增加节点类型筛选，便于在复杂画布中快速找到所需节点。
- 修复缩小画布后使用触控板双指平移时偶发跳回原位置的问题。
- 节点详情内不与滚动列表冲突的区域可继续平移画布，详情区域也支持画布缩放。
- 修正已导入音视频的素材状态展示，重跑失败时仍保留已有素材提示；图片节点创建与恢复时按实际预览高度避让。

### 画布任务恢复与交付状态

- 在创建、修改、导入和生成前登记交付任务，跨回合继续保留原目标、开始状态和操作记录，减少成果已生成却因事后登记而无法交付的问题。
- 创建成功但回执记录失败时，保留真实节点并核对已有结果；恢复时优先继续原任务，避免为了补登记而重复创建或重新生成。
- 修正目标关联时只能使用原任务内有可信创建记录的成果；恢复不会降低原验收要求或重置生成预算。
- 对话直接展示实际交付终态。阶段待办完成或助手文字中的“完成”不再掩盖交付检查未通过；普通问答、只读检查、画布整理和停止操作仍可独立使用。

### 音视频检查与资源控制

- 按用途区分预演和正式交付，并分别记录技术检查、样本内容评审和完整视听验收要求，支持尺寸、时长及是否需要音轨等条件。
- 对实际采用的媒体进行完整技术解码与有界抽帧，抽帧计划缺失时明确失败。内容评审绑定实际看到的样本及精确素材版本，换用新素材后旧评审不能继续作为通过依据。
- 媒体检查使用分块读取和临时文件快照，避免一次性把整个文件载入内存。新检查样本仅供下一次模型请求使用，响应后释放，不重复保存在会话历史中。
- 限制单次检查文件、帧数和样本总量，并支持取消与临时文件清理，控制连续评审时的内存和磁盘开销。

### 拼图预览与更新入口

- 内置等比例拼图工具，避免把竖版原帧强制拉成横版格子。制作规则要求结合原比例单帧和缺陷局部验收，减少把拼图变形误判为生图问题。
- 更新下载入口统一指向本仓库的最新 Release，避免跳转到官方站点下载其他版本。
- 内置画布制作规则升级至 `1.0.38`，补齐专业编排、设计交接、聊天协作、任务恢复、媒体验收和预览比例要求。

## 升级说明

- 基于官方 `v0.19.53`，Bone 构建号递增为 `3`；提供 macOS Apple Silicon、macOS Intel、Windows x64 和 Linux x64 安装包。
- 旧历史缺少可信创建记录时，不自动追认为原任务新建成果；已有素材保留，恢复时需如实核对。更新不会自动重跑原画布或补充生成。
- 当前媒体内容检查支持视频抽样评审，音频仅支持技术检查；完整视频语义、完整音轨内容和音画同步仍需具备相应能力的检查或人工验收。要求完整视听验收时会明确提示受阻，不能用抽样冒充全片通过。
- 专业流程仍依据实际工具能力执行；后台浏览器交互、本地视频后期及完整视听验收存在能力边界时会保留成果并说明阻塞，专业角色或阶段齐全不代表作品质量已达标。
- 分块读取和样本释放用于控制资源开销，本版不承诺未经实测的整应用内存下降比例，也不保证生成模型每次达到创作要求。
- 本版 macOS 安装包沿用未签名分发。若系统提示应用已损坏，确认安装包来自本仓库后，将应用放入“应用程序”，再执行 `xattr -dr com.apple.quarantine /Applications/Proma.app`。
