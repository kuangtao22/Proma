## 更新内容

### 项目制运维与数据库工作台

- 运维按项目管理服务器、MySQL 和 Redis 连接，支持添加、重命名、删除空项目，以及在项目之间移动连接。
- 服务器连接保留终端、文件、服务和日志能力；数据库和 Redis 进入各自的数据服务页面，项目列表和操作布局与 Proma 原生风格统一。
- MySQL 工作台区分实例级概览、参数和诊断，以及当前数据库的表浏览、会话和语句分析；表浏览支持结构、索引和分页数据。
- 连接表单支持测试当前输入、显示或隐藏密码，并统一测试入口位置；优化长表单、窄面板和深浅主题的排版。

### SQL 查询、历史与输入辅助

- 新增受控的只读 SELECT 查询，查询结果和历史通过页签切换；执行后的语句按连接与数据库保存在本机，重复语句去重，回填历史不会自动执行。
- SQL 编辑器提供表名、字段和别名联想，支持语法高亮、快捷键及可定位的中文校验提示；执行前再次核验最新语句和数据库上下文。
- 表目录和结构使用有界本地缓存，字段按需加载并可手动刷新；查询结果与业务行不缓存，结构缓存不会替代实时权限检查。
- 修复空编辑器多行示例撑大活动行背景的问题；数据库错误与查询前审计准备错误分别提示，明确语句是否已经执行。

### Agent 运维访问

- 支持向当前 Agent 会话授权指定连接及数据库表范围，读取服务器概览、数据服务诊断、表结构和有界数据。
- SQL 查询权限独立授权，保留只读、敏感字段检查、超时、取消及返回量限制；操作记录只保存必要摘要，不保存查询结果或 SQL 正文。

### 独立媒体配置与画布

- 图片与音频生成使用独立供应商配置，提供连接测试、模型获取和音色选择；画布可按供应商或模型限定生成范围。
- 接入即梦和 MiniMax 图像执行能力及图生图输入，支持自定义图片尺寸，并向 Agent 开放相应能力。
- 媒体配置采用页签和列表布局；失效模型保留明确提示，尚未接入执行器的能力不会显示为可执行。

### 日常体验与稳定性

- 优化 Agent 自动命名与 Bridge 会话命名，文件引用在确认真实存在后才变为可点击入口。
- 修正内置浏览器与模态弹窗的遮挡，补齐 Skills 关闭与移除的区分、表格焦点及列边界、Vault 双链和侧栏快捷键提示。
- 更新缓存仅在新版实际启动且窗口健康后清理；官方版本历史入口适配迁移后的官方仓库。

## 升级说明

- 基于官方 `v0.19.53`，Bone 构建号递增为 `4`；提供 macOS Apple Silicon、macOS Intel、Windows x64 和 Linux x64 安装包。
- 首次使用 SQL 查询时，本地操作记录可能需要初始化。请先完成其他版本中的运行任务，退出其他 Proma 实例后重试；这不会升级或修改远端数据库。
- SQL 查询目前限于受控只读 SELECT，不支持任意写入语句；语法校验通过后，仍需通过实时结构、权限及敏感字段检查。
- 查询历史仅保存在本机；应用不会把查询结果作为结构缓存保存。Agent 读取仍需明确授权。
- macOS 安装包沿用未签名分发。若系统提示应用已损坏，确认安装包来自本仓库后，将应用放入“应用程序”，再执行 `xattr -dr com.apple.quarantine /Applications/Proma.app`。
