## 更新内容

### SQLite 与数据库连接

- 服务器运维新增 SQLite：通过 SSH 只读访问服务器上的数据库文件，支持表目录、结构、分页数据和受控 SELECT 查询，无需下载数据库。
- MySQL 新建连接默认优先使用 TLS，仅服务器明确不支持时允许回退；同时提供必须 TLS、校验证书等策略，并展示实际连接状态。Redis 保持独立的 TLS 规则。
- 明确远程域名和 IP 的直连方式，无 SSH 服务器时提前解释可用路径；MySQL 连接表单移除库名，连接后再选择数据库。

### Agent 运维授权与读取

- 运维模块集中提供「Agent 只读授权」入口，可选择指定连接和库表范围，并切换只读工具模式。
- 只读授权按会话独立保留 30 分钟，切换对话不会撤销其他会话的有效授权；停止当前运行与撤销授权分别处理。
- 只读模式限制本轮可用工具，读取返回前再次核验权限、连接身份与凭据版本；旧服务器操作授权的替换会明确提示影响。
- 增加有界读取队列，减少界面与 Agent 同时读取产生的忙碌错误；取消、撤权和连接变化会使旧结果失效。

### 多条件筛选与性能

- 表数据支持展开筛选面板，选择字段与条件进行组合筛选；条件在数据库端执行，折叠面板保留尚未应用的输入。
- 减少 MySQL 行预览的重复查询，在服务端限制大字段预览传输量，同时保留空值、二进制大小、字段类型和分页语义。
- 优化表结构加载与界面更新，业务行数据和授权状态仍实时核验。
- SQLite 敏感字段识别使用完整列名，避免超长列名的展示截断影响遮罩。

### 运维界面

- 统一页签、选库、刷新及筛选按钮的高度、圆角和背景，调整面板间距。
- 数据源弹窗沿用 Proma 原生风格，名称与 TLS、用户名与密码分别同排，窄窗口自动单列并固定底部操作。
- 已保存密码默认显示固定星号占位，点击眼睛才按需回显；恢复隐藏时释放取回的明文，并保留用户新输入的密码。

## 升级说明

- 基于官方 `v0.19.53`，Bone 构建号递增为 `5`；提供 macOS Apple Silicon、macOS Intel、Windows x64 和 Linux x64 安装包。
- SQLite 所在服务器需安装 Python 3.11+ 并包含 sqlite3 标准库；当前仅支持 SSH 只读访问，不提供 SQLite 写入或任意远程命令执行。
- 现有连接的 TLS 策略不会因升级自动放宽。优先 TLS 可能回退到明文；需要保证加密或校验服务器身份时，请选择对应策略。
- Agent 读取需显式授权，授权内容会发送给当前模型；只读工具模式与普通模式的权限边界不同，不应把普通模式视作运维沙箱。
- macOS 安装包沿用未签名分发。若系统提示应用已损坏，确认安装包来自本仓库后，将应用放入“应用程序”，再执行 `xattr -dr com.apple.quarantine /Applications/Proma.app`。
