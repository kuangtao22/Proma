## 更新内容

### 服务卡片授权与禁用表

- 将 Agent 授权入口移到每张服务卡片右上角，点击后只管理当前连接；详情页仍可管理对应服务。
- 已配置的 MySQL、SQLite 业务基础表默认允许普通顶层 Agent 会话只读访问，不再需要反复保存数据库临时授权。
- 通过「选择禁用表」直接多选不允许 Agent 读取的表：选中即禁用，未选和新增表默认可读；规则按连接与数据库持久保存。
- 从服务卡片打开时可直接选择数据库，无需先进入工作台；支持搜索表名，大型数据库可按需搜索全部表。
- 统一保存与取消，切换数据库保留其他库的禁用项；切换项目或会话清空旧编辑目标，原样保存不会续期其他服务授权，撤销仅影响当前连接。

### Agent 运维场景

- 支持生成 SSH、MySQL、SQLite、Redis 连接配置草稿，在运维表单中核对参数、填写凭据、测试并保存。
- 扩展服务发现、独立授权日志读取与数据库变更上下文，便于结合项目代码和表结构生成迁移、修复脚本或程序。
- 数据库数据和结构修改继续采用生成可审核文件的方式，不开放 Agent 直接写库或自动执行数据库变更。

### 查询保护与界面

- 单表、联表查询增加数据库端执行限时、锁等待限制及取消收尾；超时后应缩小条件或检查索引，不自动重试原查询。
- 保留逐表访问校验、审计与连接身份复核，策略变化使旧读取失效；损坏的禁用规则会阻止读取。
- MySQL 系统库、视图、SQLite 虚拟表及实例全局诊断不因默认只读而开放；SSH、Redis 和日志继续使用会话授权。
- 运维顶部直接显示项目并支持切换，将连接身份、数据库选择和功能页签按业务层次排列，改善窄面板布局。

## 升级说明

- 基于官方 `v0.19.53`，Bone 构建号递增为 `6`；提供 macOS Apple Silicon、macOS Intel、Windows x64 和 Linux x64 安装包。
- **数据库访问规则已调整为默认只读、按表禁用。旧版禁用项仅保存在临时授权中，重启后无法自动迁移；升级后请先重新设置需要禁用的表，再让 Agent 查询。** 未禁用表的查询结果可能发送给当前模型。
- 使用新规则前，请完整退出仍在运行的旧版本实例。旧版本不识别持久禁用规则，无法保证跨版本即时生效。
- SSH、Redis 的实际授权变更仍沿用同一会话的共享 30 分钟期限；数据库禁用规则不随该期限到期。
- 查询限时能降低长查询风险，但仍受数据库引擎检查点和锁等待行为影响，不能替代数据库资源治理。
- macOS 安装包沿用未签名分发。若系统提示应用已损坏，确认安装包来自本仓库后，将应用放入“应用程序”，再执行 `xattr -dr com.apple.quarantine /Applications/Proma.app`。
