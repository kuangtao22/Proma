## 更新内容

### 本地 SQLite 数据库

- 在「新建数据源 → 连接方式」中选择「本地数据库（SQLite）」，选择本机数据库文件后即可查看表结构、浏览数据和执行只读 SQL。
- 将 `.db`、`.sqlite`、`.sqlite3` 文件拖入整个服务器运维面板时，显示虚线边框与导入说明，松开后添加到当前项目并打开。
- 拖拽提示覆盖项目页、连接页和展开的数据库工作台；移除项目页常驻导入栏，减少日常浏览时的界面占用。
- 原地只读打开数据库，不复制整库；查询在独立进程执行，支持超时与取消，减少长查询对界面的影响。
- 绑定数据库文件身份，文件被替换后要求重新添加连接，避免沿用旧目标的缓存与 Agent 禁用表规则。

### 单元格全文与 JSON 查看

- 点击数据浏览中的单元格，可以查看完整内容并复制，解决表格中长文本显示不全的问题。
- JSON 内容支持原文和格式化视图切换；格式化保留大整数、重复键和字符串内容，复制使用当前显示模式。
- 长字段按需读取，数据已变化时提示刷新，避免把旧预览对应到其他内容。
- 敏感字段继续遮罩；单格原文读取上限为 1 MiB，超过上限时给出提示。

## 升级说明

- 基于官方 `v0.19.53`，Bone 构建号递增为 `7`；提供 macOS Apple Silicon、macOS Intel、Windows x64 和 Linux x64 安装包。
- 本地数据库首期支持普通未加密 SQLite，不支持 SQLCipher、DuckDB、Access 或数据库服务端的数据目录；移动或替换文件后请重新添加连接。
- 本地 SQLite 沿用运维数据库的默认只读与按表禁用规则；不希望 Agent 读取的表，请先设置禁用。未禁用表的查询结果可能发送给当前模型。
- 从 Bone 5 或更早版本升级时，原临时禁用项无法自动迁移，请重新设置需要禁用的表，并完整退出仍运行的旧版本实例。
- macOS 安装包沿用未签名分发。若系统提示应用已损坏，确认安装包来自本仓库后，将应用放入“应用程序”，再执行 `xattr -dr com.apple.quarantine /Applications/Proma.app`。
