## 更新内容

### Agent 停止与提示框修复

- 修复运行中追加或排队消息后，后台已结束而界面仍显示运行中、反复点击停止也无法恢复的问题。
- 统一工具栏、问答和审批横幅的停止行为，收到后台结束确认后再恢复输入，避免新旧任务交错。
- 页面重载时，迟到的运行和问答快照不会重新显示已结束的任务；恢复时保留尚未发送的输入内容。
- 修复聊天提示框被右侧内嵌浏览器遮挡，长提示在窄聊天区域内自动换行。

### PostgreSQL 与数据库连接

- 运维数据源新增 PostgreSQL，支持数据库与 schema 选择、表结构和数据浏览、筛选、单元格全文、只读 SQL 及运行诊断。
- PostgreSQL 支持直连、SSH 隧道和 TLS；查询支持超时与取消，取消请求会传递到数据库服务端。
- MySQL 和 PostgreSQL 记住上次成功选择的数据库，重新打开工作台时恢复。
- 新建连接默认收起高级选项，PostgreSQL 留空时使用 postgres；已有默认库可在高级选项中查看、修改或清空。

### Windows 与首次启动

- 修复 Windows 创建或保存运维项目时，原生配置锁无法在 Electron 中正确加载的问题。
- 全新安装时自动创建运维配置目录，避免首次启动因目录缺失而无法完成初始化；已有配置继续保留。

## 升级说明

- 基于官方 `v0.19.53`，Bone 构建号递增为 `8`；提供 macOS Apple Silicon、macOS Intel、Windows x64 和 Linux x64 安装包。
- 数据库访问继续默认只读。Agent 仅能读取会话已授权范围内、未禁用的业务表；不希望发送给模型的表，请先设置禁用。
- 从 Bone 5 或更早版本升级时，原临时禁用项无法自动迁移，请重新设置需要禁用的表，并完整退出仍运行的旧版本实例。
- macOS 安装包沿用未签名分发。若系统提示应用已损坏，确认安装包来自本仓库后，将应用放入“应用程序”，再执行 `xattr -dr com.apple.quarantine /Applications/Proma.app`。
