## 更新内容

### 接口工作台（新）

- 侧边栏新增独立的「接口」工作区：可保存 HTTP 请求（方法 / URL / Query / Header / 正文 / 鉴权）、集合与环境变量；运行记录逐跳保留状态码、响应头、耗时与连接事实，历史按 7 天 / 1 GiB 保留，敏感值在记录与预览里统一遮罩。
- 普通交互 Agent 与界面共用同一套执行服务：Agent 可列出接口、读定义、准备请求、在获得批准后发送、按需读取运行记录（含事件流分页与断言结论），不会自动重放历史请求，也拿不到已保存的秘密明文。
- 支持 cURL 导入与导出、集合快照分享：导出时秘密替换为 `{{变量}}` 占位符，导入后必须重填才能发送。
- 支持事件流（SSE）实时查看与逐帧断言、从响应里提取变量并在后续请求用 `{{name}}` 复用（取值只写会话内存）、运行时变量面板。
- 支持自动 Cookie Jar：默认关闭、只活在主进程内存、按 host-only 记录，Cookie 取值不出主进程。
- 支持历史运行「载入编辑器」：把该次实际生效的请求还原成新的未保存草稿，被遮罩的位置留空并列出必须重填的地方，不伪造值。
- 支持 JSON 类型断言与两次运行的响应差异比较（状态码 / 响应头 / 断言结论 / 正文变化），对比只读默认脱敏投影。
- 支持具名测试用例：一条接口可保存多条用例（断言 / 变量覆盖 / 环境），可一键跑全部用例并复制 Markdown 报告；Agent 可以新增用例并在报告里标注来源，人工创建的用例不允许被 Agent 修改或删除。
- 支持 multipart 表单上传：界面用原生文件对话框选择文件；Agent 可以指定本机文件路径，但必须在确认授权弹窗上逐行看清按 realpath 解析后的真实路径与大小，该弹窗被批准后才会读取文件。文件引用只活在主进程内存、重启后需要重新选择，附件内容不写入运行记录。

### 本机数据源凭据发现

- 连接本机回环地址（`127.0.0.1` / `::1` / `localhost`）的 MySQL、PostgreSQL、Redis 时，数据源弹窗提供「从本机查找凭据」：按发布地址与端口匹配本机容器，读取候选账号与口令并一键填入草稿。
- 只写草稿：不自动保存、不自动测试；只支持回环地址，不读取用户目录或项目文件，也不接受手输路径。

## 升级说明

- 基于官方 `v0.19.53`，Bone 构建号递增为 `9`；提供 macOS Apple Silicon、macOS Intel、Windows x64 和 Linux x64 安装包。
- 接口工作台的文件引用与 Cookie 只存在于主进程内存：应用重启后需要重新选择文件，已保存请求里的文件引用会提示「需要重新选择文件」。
- 数据库访问继续默认只读。Agent 仅能读取会话已授权范围内、未禁用的业务表；不希望发送给模型的表，请先设置禁用。
- macOS 安装包沿用未签名分发。若系统提示应用已损坏，确认安装包来自本仓库后，将应用放入“应用程序”，再执行 `xattr -dr com.apple.quarantine /Applications/Proma.app`。
